Plan de tests — Projet QAOps

Automatisation des tests et assurance qualité d’une application web
Version 1.0 · 4 octobre 2026

1. Objectif et périmètre

Ce plan couvre les parcours UI du site de démonstration Formy Project et les endpoints CRUD de Reqres. Les tests de charge et de sécurité sont documentés dans le rapport final. Les données de test sont fictives et les cibles sont exclusivement celles imposées par le sujet.

Hors périmètre : aucune application tierce, aucune donnée réelle, aucun compte personnel, aucune analyse hors des hôtes formy-project.herokuapp.com et reqres.in.

2. Environnement

  • macOS, Google Chrome 154 et Selenium WebDriver
  • Node.js, Mocha et Allure Report pour les tests UI
  • Postman/Newman pour l’API Reqres
  • JMeter pour la charge et OWASP ZAP pour l’analyse de sécurité
  • Jenkinsfile pour l’intégration continue

4. Traçabilité

Les scripts Selenium sont dans tests/ui/formy.spec.js. La collection API exportable est postman/reqres-collection.json. Chaque scénario est identifié par son code QA-UI ou QA-API dans le dépôt et les rapports d’exécution.
